# ЖЕЛЕЗО.МАРКЕТ — remake

Современный визуальный ремейк учебного проекта kr1-html-css-shop:
интернет-магазин комплектующих и готовых сборок ПК.

Взята содержательная база проекта-референса CompMaster (структура страниц, разделы,
фильтры каталога, страница товара по `?id=`, отзывы, контакты, статистика, тёмная/светлая
тема, анимации), но дизайн полностью новый и независимый.

Особенности:

- тематика: продажа комплектующих и готовых сборок ПК;
- актуальное поколение железа: RTX 50 (Blackwell), Radeon RX 9070 XT, Ryzen 9000, Core Ultra 200S, DDR5-6000, PCIe 5.0 SSD (20 позиций);
- чистый HTML + CSS + JavaScript, без фреймворков и библиотек;
- методология БЭМ в разметке и стилях;
- адаптивная вёрстка, светлая и тёмная темы с запоминанием выбора;
- каталог с фильтрами по категориям и цене, живым поиском и сортировкой (цена / рейтинг);
- карточки товаров с брендом и рейтингом, страница товара `product.html?id=N`;
- русская и английская локализация интерфейса с переключателем в шапке (выбор запоминается);
- личный кабинет `account.html`: вход по имени и телефону, история и демо-отслеживание статуса заказов (localStorage, без сервера);
- все изображения товаров — инлайн-SVG, внешних ассетов нет (кроме Google Fonts).

Атрибуция: иконки категорий и товаров — [Lucide](https://lucide.dev) v1.77.0, лицензия ISC (иконка gpu нарисована вручную в том же стиле).

Страницы:

- `index.html` — витрина: hero, категории товаров, призыв к заявке;
- `catalog.html` — каталог с фильтрами (товары и сборки живут здесь);
- `product.html?id=N` — карточка товара (данные из `js/main.js`);
- `reviews.html` — отзывы и форма «Оставить отзыв»;
- `about.html` — о магазине: статистика, преимущества, этапы «как заказать»;
- `contacts.html` — контакты, интерактивная карта, обратная связь, вопрос-ответ;
- `account.html` — личный кабинет с отслеживанием заказов.

Запуск: открыть `index.html` в браузере или поднять любой статический сервер.
